Cómo optimiza las rutas el motor VRP

Arquitectura ligera sin API Keys obligatorias, combinando red viaria real y optimización combinatoria.

Paso 1

Matriz de Tiempos por Carretera

Geocodifica direcciones con Photon/Nominatim y consulta la API pública de OSRM Table para estimar la matriz real de conducción entre todas las clínicas y el almacén (con fallback Haversine offline).

Paso 2

Algoritmo VRP Multi-Técnico

Construye rutas iniciales dispersas, aplica mejora intra-ruta 2-Opt y ejecuta búsqueda local Relocate / Swap para minimizar el tiempo total de conducción equilibrando la jornada entre técnicos.

Paso 3

Mapa e Itinerario Accionable

Traza las polilíneas reales calle a calle en Leaflet, calcula horas exactas de llegada/salida sumando el tiempo de reparación y genera los enlaces de despacho para todo el equipo.
